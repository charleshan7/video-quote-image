# 版式、真实帧与品牌

## 默认版式 A

画布 1440×1920，主画面比例 0.362。剩余高度按实际引用数等分；不要使用全局固定 `--bands` 截断引用。

中文默认 52px、英文 28px、时间码 24px。渲染器的 overflow warning 会阻断 reviewed/final；应换句、增加条带高度或显式调整版式，不得静默截断。

## 字体

渲染器会自动寻找 Noto CJK、macOS STHeiti/PingFang 或 Windows 微软雅黑，并做中文字形检查。自动发现失败时显式传字体路径。实际路径会写入 `render.json`；禁止静默回退到 Pillow 默认字体。

## 烧录字幕

渲染前抽查多个时刻：

- `verified-absent`：确认原画面没有烧录文字。
- `cropped`：原字幕位于底部，使用 `--source-crop-bottom` 从所有真实帧中裁掉该区域并在原尺寸复核。
- `unknown`：尚未确认；只能用于 draft。

裁切后仍出现原字幕，或字幕位于不可安全裁掉的位置时，应更换视觉方案或停止，不要让原字幕和重绘文字叠加。

## 真实帧

`time` 记录引用来源，`frame_time` 记录画面。每句围绕来源时间至少比较 5 帧；头图在相关主题宽窗口至少比较 8 帧。候选和最终选择必须写入 `frame_audit.json`，preflight 会核对选择是否属于候选集合且与 spec 一致。

## 品牌

默认使用版本库内 `assets/brand`，确保不同机器输出一致。只有用户明确指定其他品牌资产时才用 `--logo-dir`。品牌图必须写入独立 `branded/`，并为每张输出品牌证据 JSON。
