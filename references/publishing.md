# 人物与发布包装

`people.json` 中每个头图人物必须有稳定 `person_id`，并记录姓名、角色类型、身份描述、HTTPS 来源 URL、支持身份的原文摘录、核验时间和 0–1 数值置信度。spec 用 `hero_subject_id` 绑定人物，不能只靠可能重名的姓名。来源优先级：原节目或机构官方页，其次人物官方页，再其次可信媒体。来源冲突时保留冲突并降级，不自行裁决。

`xiaohongshu_package.md` 至少包含：

- 人物介绍：采访/演讲/纪录片关系和可核验身份。
- 8–15 个标题候选及淘汰原因，首发标题绑定证据 `quote_id`。
- 一句封面大字。
- 正文：来源、核心冲突、关键证据、现实含义和讨论问题。
- 轮播顺序：每张绑定实际 `image_id` 和全部 `quote_id`。
- 评论区引导和 8–15 个话题标签。

标题可以有张力，但不得把推断写成受访者原话。preflight 会检查每个最终 ID 是否实际出现在发布包中；仅保留空标题或关键词模板不能通过。
